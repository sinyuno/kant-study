# Git Tutorial

```sh
# 깃 초기화
git init

# 스테이징에 추가
git add .
git add -A
```

```sh
# commit 
git commit -m "commit message..."
```

```bash
# push 명령어

git push origin main
```

```sh
# git 로그 명령어

git log
git log --oneline
git log --oneline --all

```

### 브랜치 생성 및 스위치

```sh
git branch 브랜치 명
git checkout 브랜치 명
git check out -b 브랜치 명
```
